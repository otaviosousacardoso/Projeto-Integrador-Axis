# AXIS - Projeto Integrador (HTML5 + CSS3 + JS básico)

E-commerce estático da loja AXIS (Fundamentos de Web Design I). Sem back-end e sem banco de dados.
Publicação: GitHub Pages (veja GUIA-GITHUB-PAGES.md).

## Páginas
- **Loja:** index, produtos, ofertas, oferta-detalhe, produto-*.html (8), carrinho, pagamento, pedido-confirmado
- **Conteúdo:** blog (com seção Sobre), sobre, faq, contato, ajuda
- **Conta:** login, cadastro, recuperar-senha, minha-conta, editar-dados, meus-cupons, meuspedidos, detalhes-pedido
- **Gestão:** admin, dashboard-funcionario, dashboard (tabela de produtos)

## Arquivos globais
`css/style.css` (grid de 12 colunas, índice no topo) e `js/main.js` (JavaScript básico). Todas as páginas usam os mesmos.

## Logins de demonstração
`admin@axis.com` e `funcionario@axis.com`, senha `1234567`. Qualquer outro e-mail vai para a área do cliente.
Todos os dados (pedidos, cupons, preços "De") são fictícios e nada é salvo.
